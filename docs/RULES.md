# 能力、规则与边界

面向 AI 监督者与高级用户的能力边界与操作规范。行为准则见 [README](../README.md)，架构见 [ARCHITECTURE](ARCHITECTURE.md)。

## 能力边界（各任务类型能做什么、不能做什么）

| 任务类型            | 能力                                                     | 边界                                                                                                                                                                                                                  |
| ------------------- | -------------------------------------------------------- | --------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------------- |
| `daily` 日常      | 开模拟器→启游戏→抽每日免费→打白纸化地球/冠位戴冠战×3 | 耗风暴罐和 AP，`count` 不生效（罐尽自然结束）；**默认用 1 号编队**，使用前先设好编队；白纸化部分关卡依赖奏章Ⅱ定位（如 90⭐），至少通关奏章Ⅰ；冠位戴冠战默认打最后一个最高难度副本，冠位认定战没打会自动补打 |
| `battle` 周回     | 连续战斗刷本、强化本                                     | 进入战斗前或主界面选本列表开始均可；主界面开始时目标本须在列表第一位；**复杂机制关可能无法自动通关**——这是 AI 接管（pause + cheat）的核心场景                                                                 |
| `main` 过主线     | 自动推进剧情与战斗                                       | **不要改变地图缩放**（缩放过要重进图）；需人工干预关卡见下表                                                                                                                                                    |
| `free` 清 free 本 | 地图上自动选关                                           | 同样保持默认缩放；**第七异闻带地图不适配**（可手动选关，固定三次战斗）                                                                                                                                          |
| `first` 首通      | 幕间/进阶/回忆等一切通关拿奖励的本                       | 以列表内关卡奖励是否已获得为基准；无奖励的周回本不适用（浪费体力）；机制关（狼人杀等）可能卡关；回忆关卡部分在边缘位置需手动点开列表                                                                                  |
| `kidou`           | 拉起模拟器→游戏→主界面                                 | 仅启动，不打任务                                                                                                                                                                                                      |

### 过主线已知需人工干预（截至当前版本）

- 第四特异点：雾遮挡标志；第六特异点：风沙遮挡；第七特异点：提亚马特遮挡
- 终局特异点：柱子战前剧情结束后无标志，柱子战需手动
- LB2 6-4、LB5 亚特兰蒂斯 11-2、LB5 奥林波斯 2-1/2-2/5-1/6-3/12-2、LB7 1-2：强制马修出战，自动编成会打乱编队——先编好马修或全程带着
- LB6 18-5：需手动放妖兰群体宝具；24-6：需送死；LB7ORT 最终战建议手动
- 奏章二：多选项找线索；奏章四：码头警告

## 操作规范

### 编队与助战

- 礼装候选最多四种，检测到其一即选；含「活动礼装」时选第一个助战（不挑助战，想选活动礼装在游戏内设好筛选）；检测到冠位助战时选满足候选两项的。
- 游戏内建议开启筛选、加快敌人消失、战斗二倍速（加快战斗速度）。
- 茶壶/风暴罐开关会强制保持一致。

### 多开

- 同一模拟器实例同时只被一个配置占用，撞实例任务会被终止（看 `reason` 字段，不是 PRECHECK_FAIL）。
- 多个同名模拟器进程：附加时弹窗选择；API 侧用 `cheat status` 看 candidates → `device connect` 带 pid 预登记，免弹窗。`start`（启动时间）是辨认进程归属的关键。

### 内存修改（cheat）规范

- **位置编号**：我方 1~N，敌人编号接在我方之后；敌人同场从右往左递增，非同场按出场顺序；未出场敌人可检测，跨面数据需进入下一面才加载。
- `servant_count` 设小于己方从者数会**误杀自己人**——宁可偏大，但一般关卡最多上6名从者，奥尔加玛丽本除外；跨面场景 = 上场从者数 + 之前面敌人总数。
- `kill_all` 一次只清当前面；多血条敌人一次只破一管，血条刷新后可再次执行。
- 数值勿超上限（默认 800 万攻 / 1000 万血是安全区），超限会导致错误或伤害归零；`npl=0` 表示 NP 直接满。
- 敌人 HP→0 = 不战而胜；**特殊机制关可能因 buff 结算出错导致无法通关**——换策略，不要无脑重试同一修改。
- **地址缓存**：每场战斗地址不通用；修改失败时先试改，失败再 `cheat clean`（战斗中直接清可能误清本场标志）；新战斗开始前 clean 是安全时机。
- 一号位特征码可能被遮挡改不到——改其他位即可。
- 修改定位按「等级+攻击力」（我方）/「等级+生命值」（敌方），OCR 有误时改失败——先 `battle_state` 核对屏幕识别值，识别数字可能有误。
- 出现闪退等异常：重启游戏或模拟器；重新进入战斗前**清空记录**。

## 确认门与不可逆操作

- 唯一确认门：彩苹果（= 圣晶石）消耗。AI 未经用户明确授权不得消耗；`pre_confirm=true` 仅在已知用户意图时使用（照发审计事件）。
- 跳剧情等非不可逆操作不过门（`main` 缺省跳剧情，带 `config_override skip_plot=false` 可看剧情+朗读）。
- 剧情朗读（Eisyou）仅支持中文（国服）。

## 计划任务边界

- 关机/休眠：等**所有**任务结束后才执行（多开时等最后一个）。
- 挂机（HALT，AP 恢复自动继续）：仅能在 MoonCancer UI 设置，API 无端点；`daily`/`kidou` 不支持；建议配合「清理剩余体力」。
- API 侧等效做法：`task start wait=true` 终态后自行判断是否再启动下一轮。

## 连接与环境技巧

- MuMu 后台保活必须**关闭**，否则截图异常；MuMu 不要用安卓 15 版（内存修改失效）；分辨率 16:9、1280×720 起步。
- 连接慢且报 `socket connection broken`：卸载模拟器内的 `yosemite` 应用；同时使用 BBChannel 时，把 `MoonCancer\assets\static` 覆盖到 BBChannel 的 `dist\BBchannel64\airtest\core\android\static` 可同时解决两边的连接问题。
- 高速连接（MuMu/雷电）出问题可切 `other` 用 adb 默认连接。
- 自动搜索成功后不要改「模拟器位置」「虚拟机进程名称」，除非明确知道自己在做什么。
- 连接超时（自动启动模拟器没连上）：调大方案 `connection_timeout`。
